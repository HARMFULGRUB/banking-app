<h1 align="center">🐐 Goat Banking App</h1>

> A minimal digital banking app built to simulate real-world account handling, transfers, and transaction tracking. This is the **Greatest of All Time** banking UI prototype.

---

### 💼 Features

- Add & manage customers/accounts
- Simulated fund transfers
- Transaction logs and mini-statements
- Clean and intuitive interface
- Built with scalability in mind

---

### 🧰 Tech Stack

- Node.js
- HTML + CSS with Tailwind
- Hosted locally
